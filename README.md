### ✨ Features V1

- 📱 **AUTO Phone Detecting** — Phone (1), (2), (2a), (3), (3a), (4), (4a), CMF 1, CMF 2 Pro
- 🔑 **AUTO Essential Button Detecting** — Learning Mode (press 3x)
- 🔋 **Screen On/Off Support**
- 🧠 State-based Automation, Glyph Sync, 30+ Actions
- 📳 Haptic, 👀 Overlay, 🎯 4 Gestures Only (Single, Double, Triple, Long)

### 🚀 Install

1. Download APK from [Releases](https://github.com/Abhiramm2400/Essential_Re-mapper/releases)
2. Install → Enable Accessibility → Enable Display over apps → Battery Unrestricted
3. Learning Mode → Press Essential Key 3x

### 🛠️ Build APK (Method 1 - GitHub)

Push to main → Actions → Build and Release APK V1 → Download Artifact
