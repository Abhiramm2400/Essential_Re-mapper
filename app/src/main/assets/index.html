Why AccessibilityService is needed: Nothing's Essential Key is a system key. Android only lets AccessibilityService with flagRequestFilterKeyEvents intercept it and block the default Essential Space. No data is collected. The service only listens for your Essential Key to remap it.

How to enable: Settings → Accessibility → Essential Remapper Pro → Enable → Allow. Then grant "Display over other apps".

Auto detection: Works for Nothing Phone 1/2/2a/3/3a/4/4a and CMF Phone 1/2/2 Pro. For Phone 3/4, Essential Key is hardware. For older phones, Learning Mode captures any key you assign.
